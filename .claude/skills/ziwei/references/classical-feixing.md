# 《飞星紫微斗数》使用说明

- 书目：《飞星紫微斗数》，题（宋）陈抟著，徐良弼校正，中州古籍出版社。底本为咸丰六年（1856）连元阁刻本。
- 仓库登记：`knowledge/ziwei/sources/catalog.yaml` 中的 `feixing-ziwei`（336 页扫描件，无文字层，作者字段为未验证线索）。
- 页码约定：本 skill 引用的 pN 为**书上印刷页码**；PDF 页码 = N + 6。
- 出版说明称：书中地盘图"东西对调"，看原书星盘图时方向要反过来。
- 默认角色：`classical-reference`，即古籍研究与交叉验证，**不直接生成用户结论**。已完成原页复核的摘录在 `knowledge/ziwei/sources/feixing-ziwei/excerpts.jsonl`，只有那些条目可以作为 A 级证据的来源。

### 十八飞星（卷一、卷二）为什么不能用

十八飞星用的是另一套星曜：紫微、天虚、天贵、天印、天寿、红鸾、天库、贯索、文昌、天福、天禄、天杖、天异、毛头、天刃、天刑、天姚、天哭（另有天空）。它的安星法（如"从未上起子，顺数至生年安紫微""从子上起正月逆数至生月安天杖""从杖星顺数生时安命"，p6–8）、大限起法（阳男阴女从命宫顺行，阴男阳女从**身宫**逆行，p8）都与三合派紫微斗数不同。

只有紫微、文昌、红鸾、天姚、天刑这几个**名字**与 iztro 盘重合，含义和位置完全不同。iztro 盘上的"紫微"不能拿卷一的"紫微星独为尊"条文来解，"天刑""天姚"也不能套卷一的断语。

若用户专门询问十八飞星体系，可以讲理论与历史，但要说明本仓库没有该体系的排盘引擎，**不能给出十八飞星命盘**。

## 二、各卷可用内容与页码

### 第三卷：安星与运限（口径对照）

- p112 起"安身命诀"，p115"安紫微天府诀"，p117"布南北二斗诸星诀"，p119–126 火铃、天马、红鸾天喜、命主、台辅、天贵、劫杀、华盖、桃花、大耗等安法，p126"生年太岁十二神""博士十二神""定大限诀"，p127"定小儿童限诀""论流年斗君法"。
- 用途：解释引擎结果的来历、回答"为什么命宫在这里"之类的教学问题。**不得用这些口诀重算或纠正引擎。** 若发现引擎与口诀不一致，记录为口径差异，不改盘。
- 已复核摘录：p126 定大限诀、p127 流年斗君法、p128 流日流时顺排。
- p141"论二限天罗""论到限"、p144–147"论大小二限太岁值十二宫断法"：把大限、小限、太岁落入各宫的吉凶逐宫列出。可提炼"大限、小限、太岁叠在同一宫时作用加重"这一层；其中"十无一生""黄泉"等断语不用。

### 第四卷：赋文

- p150–152 **太微赋**（原文）：全书总纲。"以身命为福德之本，加以根源为穷通之资""星临庙旺，再观生克之机；命坐强宫，细察制化之理""诸星吉逢凶也吉，诸星凶逢吉也凶"。
- p152–153 **形性赋**：各主星的形貌与性情，可用于讲星情（性格倾向），外貌描述只作背景。
- p153–194 **星垣论**：逐星论述，是讲单星星情时最直接的参考。
- p194 太岁妙论，p197 提要六问断。

### 第五卷：赋文注解

- p202 玄微论（"辨宾主之分""审动静之机"），p203 准绳论。
- p205–236 **玉蟾发微论**（副题"斗数指南"）：前半是一长串格局口诀加小字注，内容与通行本《骨髓赋》大体相同，如"夹日夹月""子午破军加官进禄""朝斗仰斗爵禄荣昌""合禄拱禄定为巨擘之臣""日月最嫌反背""身命定要精求，恐差分数"（p208–224）。格局速查表的主要来源。女命赋与太微赋注解也收在这一节之下。
- p225–227 **女命赋**：按性别给出婚姻、贞洁评判，与安全策略的性别刻板条款冲突，**整体不用**。
- p228–235 **太微赋注解**：对第四卷太微赋的逐句注释，用于理解赋文含义。
- p237–248 **论身命十二宫吉凶星便览**：十二宫逐星的庙旺 / 陷地断语。可提炼"某星在某宫亮度好坏时的倾向"，但"天折""屠人"、寿数（如 p247 福德宫按星给出寿岁）一律不用。

### 第六卷：方法论与格局

- p249 **十二宫禄权科忌庙照论**：按地支说明四化得地与否。已复核为方法性摘录（四化须结合宫位状态）。
- p249–250 **十二宫诸星生克制化论**：星曜五行与宫位五行的生克，"受制""得地"的判断方法。
- **p249–270 已全部逐页原图校订入库**，共 36 条新摘录（`source.feixing-ziwei.p249.*` 至 `p270.*`），身份、寿夭、性别断语按安全策略只录体例不录原句。
- p250–253 **看命总论 / 看命或法**：正、合、拱、夹的定义（已复核摘录 p250）；"帝星不宜独立""杀曜不可群居"；"大限十年之祸福，小限一岁之荣枯；大限既衰，小限何补"；看命先命主、次身主。**读盘次序的主要依据。**
- p253 十二宫诸星失陷贫贱论，p254–256 定富局、定贵局、定贫贱局、定杂局（格局名录，附简短成立条件）。
- p256–258 定富贵贫贱一十四等决，p258–259 定富贵贫贱十等论：把组合对应到身份等级，**不引用**。
- p259–262 十二宫诸星得地合格决 / 失陷破格决：按命宫地支列格局，只提炼"得地 / 失陷"的结构信息。
- p263–264 流年二十四位神煞吉凶：太岁十二神、博士十二神的含义。
- p264–276 诸星格局皆取贵论（各格有诗）、论不合局（命无正曜、机月同梁等）。
- p276–278 论太岁、论叠叠杀、论羊陀迭并："限行重见"即运限与本命叠煞，与 `mutagen_stack`、运限叠宫的思路一致。
- p278 起 诸星所属化变（各星五行与化气）。
- p280–299 **古今命例**：状元、宰相、国公、富商、太监等十余张历史命盘，标注宫位星曜与五行局。只作研究，不作为用户盘的对照模板。

### 附录：近代命例分析（p300 起）

今人所写的名人命造分析（徐树铮、段祺瑞、张作霖、孙中山等），按三合法先论命宫星曜与会照，再按大限逐段推演，并结合"化忌入原局某宫及大限某宫""大限与原局叠宫"讲运势起伏。

- 可借鉴的是**写法**：先本命、后大限；每个大限说清"大限命宫在哪、四化入哪、与本命叠成什么"。这与本 skill 的"静态先于动态"一致。
- 不可借鉴的是**结论方式**：附录多次以星曜推断死亡年份与死因，属于安全策略禁止的内容。

## 三、使用规则

1. 本书条目在报告中只能以"按古籍的说法""传统上认为"引出，并按 `analysis-method.md` 第七节转译。
2. 引用时给出书名与印刷页码即可，不在报告里大段抄录原文。
3. OCR 文本错字较多（如"卯"识别成"卵"，"贪"识别成"贫"，"巳"识别成"已"），引用前要按上下文校正；关键结论需要原页复核才能写入知识库。
4. 想把某条古籍规则正式纳入知识库，按仓库流程推进：`draft_ocr → extracted → visually_verified → cross_checked → reviewed`，并写入 `knowledge/ziwei/sources/feixing-ziwei/`。整书 OCR 与页面图片不进 Git。
