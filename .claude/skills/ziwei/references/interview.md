# 紫微访谈模板

正式排盘前做两段式访谈，语言直白，一次问清核心项。

## 第一轮：核心问题

1. 你的出生日期？（公历优先。若是农历请说明，并告诉我是否闰月，我先帮你换算成公历。）
2. 出生的具体时间，尽量到分钟？这是钟表时间，还是已经按出生地换算过的真太阳时？（若给出出生地城市，脚本会自动换算真太阳时，可一并询问出生地）
3. 性别？
4. 你这次主要想看什么？一句话说清（如：我适合什么样的工作 / 未来两年事业有什么变化 / 感情模式 / 整体命盘）。
5. 时间范围？（只看命盘 / 当前这个十年 / 今年 / 某几年）
6. 你最想得到的判断？（结构倾向 / 哪几年变化大 / 要注意什么 / 只想了解自己）
7. 你要"直接结论"还是"详细讲解"？

## 第二轮：按条件追问

- **没有出生时间**：紫微命宫由时辰决定，没有时辰无法排盘。问是否能查到出生证明或问家人；实在没有，建议改用八字（可用三柱）或只做理论讲解。
- **只知道大概时段**（"早上""半夜"）：说明可能跨两个时辰，问能否缩小范围；必要时两个时辰各排一盘，请用户用过往经历对照。
- **时间离奇数整点不足 15 分钟**（如 08:55、15:08）：提醒可能落在相邻时辰，问时间是否准确、是否是真太阳时。
- **只给了农历**：确认是否闰月，换算成公历。
- **问题太泛**（"看看我的命"）：问最关心的一个方面，映射到 overall / career / wealth / relationship。
- **问"哪年"**：确认年份区间（最多 10 年），映射到 `cross_period`。
- **问具体单件事成败**（"这次面试能不能过"）：说明紫微看结构与阶段，单件事更适合奇门；用户仍要紫微时，用流年层看该年相关宫位的变化，并降低确定性。
- **高风险主题**（健康、官司、重大投资、孕产）：说明命盘只做结构提醒，建议同时寻求医生、律师、财务顾问等现实专业帮助。
- **用户提供了过往事件**：记录年份与事件类型，解读时对照当年的大限、流年叠宫做校验，并说明这是校验而非倒推改盘。

## 进入正式排盘的最低条件

- 公历出生年月日 + 精确到分钟（至少能确定时辰）的出生时间 + 性别。
- 主题能归入 overall / career / wealth / relationship 之一。
- 若看运限：年份或区间明确。

满足后组装 JSON，调用 `scripts/ziwei_skill_cli.cjs`。
