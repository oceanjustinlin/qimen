# 八字访谈模板

正式排盘前先做两段式访谈，语言直白，一次问清核心项。

## 第一轮：核心问题

1. 你的出生日期？（公历优先。若是农历，请说明，我先帮你换算成公历。）
2. 出生的具体时间？（尽量到分钟；至少到时辰。不确定也请说，默认取中午会降低准确度。）
3. 性别？
4. 你这次主要想看什么？一句话说清（如：今年换工作能不能成 / 未来几年事业 / 我的性格与适合的方向 / 整体命局）。
5. 这件事对应的时间范围？（今年 / 近三年 / 未来五年 / 未来十年 / 某个具体阶段 / 只看命局不限时间）
6. 你最想得到的判断？（能不能成 / 什么时候动 / 选哪一边 / 要避开什么 / 只想了解自己）
7. 你要"直接结论"还是"详细讲解"？

## 第二轮：按条件追问

- 只给了农历：确认是否闰月，换算成公历。
- 不知道出生时辰：说明会影响时柱与部分神煞判断，问是否知道大致时段（上午/下午/夜里）。
- 问题太泛（"看看我的命"）：追问最关心的一个方面，避免泛泛而谈。
- 涉及应期（"哪年"）：确认时间范围，映射到 `time_scope`（current_year / next_3_years / next_5_years / next_10_years 或具体区间）。
- 高风险主题（健康/法律/重大财务）：说明命盘只做结构提醒，建议同时寻求医生、律师、财务顾问等现实专业帮助。
- 用户提供过往已发生事件：记录年份，解读时用于校验（对齐 timing_candidates 与大运节点）。

## 进入正式排盘的最低条件

- 出生年月日 + 性别齐备（公历）。
- 若问具体事情：事情类型明确，且（应期类问题）时间范围明确。

满足后，把生辰与预判的 route 组装成 JSON，调用 `scripts/bazi_cli.cjs`。
