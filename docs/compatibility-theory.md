# 双人合盘理论框架：从单盘推演到双盘推演

> 状态：设计稿（2026-11-16）。配套工程文档见 [`compatibility-redesign-spec.md`](./compatibility-redesign-spec.md)。
> 主要依据：陆致极《命运的求索：中国命理学简史及推演方法》（下称「陆著」，页码为书内页码）；项目现有八字引擎（`lib/baziCore.js` 等）；线上「朋友合盘」实现（`public/wrapped.html`、`worker/src/index.js`）。

## 1. 结论先行

1. **陆著没有合婚或合盘的章节。** 它提供的是一套严谨的单盘推演程式（强弱、调候、格局、形象、综合评价，再到性情、六亲、岁运），以及对命理学局限的清醒交代。所以合盘理论不能从书里抄，只能从书里**推**：把单盘程式一致地延伸到两张盘上。本文每条规则都标注了依据等级，哪些是书证、哪些是通行说法待核、哪些是本设计的推演，一目了然。
2. **核心命题只有一个：对方如运。** 一个人长期在场，对我的命局而言相当于一股持续存在的外来之气，其作用方式与大运流年作用于原局同构，只是力度更弱、且只在相处时生效。有了这个命题，单盘里已经成熟的全部法则（喜忌、调候、病药、刑冲会合、星宫并看、应期）都可以原样复用，不需要另造一套拍脑袋的权重表。
3. 由此得到一个**五层模型**：底色（各自单盘）、互济（气的补益）、勾连（干支的合冲）、角色（十神与宫位的映射）、同步（岁运的时间维度），外加一个只展示不计分的民俗与神煞辅证层。
4. 综合评价不再是一个「合不合」的总分，而是**四问**：有没有缘（牵系）、处得顺不顺（张力）、谁滋养谁（互济，分方向）、走不走得久（底色与同步）。牵系和吉凶是两回事：合得紧不等于处得好，这是现有实现里最大的概念混淆。
5. 现有「朋友合盘」的评分逻辑与上述理论有几处直接冲突（见第 9 节），其中最典型的是：传统上最被看重的日干五合（陆著所说「夫妻克合」），在现有算法里恰好恒等于 0 分。

## 3. 从单盘到双盘：七条基本命题

**P1 单盘先于合盘。** 两个人合不合，先看各自命局里这类关系本身的底色。陆著分析康熙的婚姻，结论完全来自他自己的盘：身强比劫旺而克制妻星，所以婚姻不顺；但妻星是喜神、妻宫申金也是喜神，所以「又是贤妻可期的征兆」（p.408）。对方的盘只能在这个底色上加减，不能推翻它。（书证）

**P2 对方如运。** 陆著的岁运分析表明，外来的干支进入命局后，会补益或损耗原局的五行，会与原局的干支发生合冲，从而引动某个宫位、某个六亲（如 p.411–412 流年戊子填实拱神、冲去午火；p.171–172 流年午火暗合苏轼妻宫而成婚，巳亥相冲而丧妻）。一个长期相处的人，其命盘对我而言正是这样一组外来干支。区别有三：力度弱于岁运（岁运是时间本身，人只是环境的一部分）；只在相处时生效，所以**相处密度**决定权重（同住的伴侣 > 合伙人 > 朋友）；它是双向的。（推演）

**P3 有向性。** 「你对我」和「我对你」是两个独立的问题。你的旺神恰是我的用神，不代表我的旺神也是你的用神。任何把两个方向取平均的做法都会丢掉关系里最有信息量的东西：谁更受益，谁在付出。（推演）

**P4 牵系与顺逆分离。** 合、冲、刑、害描述的是两张盘之间**作用的强度与方式**，不直接等于吉凶。陆著处理单盘时始终如此：合可以是合去忌神，也可以是合绊用神；冲可以冲去病神，也可以冲坏根基（p.403 巳申合「使申金合辰之情不专」，是瑕疵；p.412 冲午则根基尽失）。所以合盘要分两步：先量牵系（有多少合冲），再用各自的喜忌判顺逆（这些合冲对谁有益、对谁有损）。（书证的延伸）

**P5 星宫并看。** 陆著定位六亲用两套坐标：十神为星（男以财为妻，女以官为夫），柱位为宫（日支为配偶宫，月柱为父母兄弟，时柱为子息，年柱为祖上，p.166 图 6.2）。合盘的角色层也用这两套坐标：对方的日主在我的十神体系里是什么星，对方的干支落在我的哪个宫上。（书证的延伸）

**P6 体用与动静。** 原局是静态分析，「是命造分析过程中的重要环节」（p.404），但应事要看岁运。合盘同理：两张原局的关系是体，两人各自的大运流年是用。同一对组合，在不同年份会呈现不同的面貌。（书证的延伸）

**P7 或然而非必然。** 陆著明言出生时间与人生轨迹之间「不是决定性的关系，它只是一种出现的几率或概率上的相关性」（p.424），并转引梁湘润「命理大约只有百分之六、七十的或然律」（p.428–429）。「四同」八字的人命运并不相同（p.425–428），两个人的相处更受后天的教养、选择、环境左右。合盘输出的是**结构上的倾向**，不是判决。（书证）

## 4. 五层模型

记两人为甲方 A、乙方 B。凡有方向的结论，写作「A 受 B」（B 的盘对 A 的作用）和「B 受 A」。

### 4.1 第 0 层 底色：各自单盘里的关系基础

对每个人单独回答：这类关系在其命局里本来的状态如何。

| 看什么 | 怎么看 | 依据 |
|---|---|---|
| 关系星的喜忌 | 该关系对应的十神五行，在此人命局中是喜用还是忌神 | 书证：康熙妻星为喜用（p.408） |
| 关系星的旺衰与受制 | 有无、透藏、得令与否、是否被邻近干支合去或克去 | 书证：苏轼妻星丙火被辛金合化，坐下亥为丙之绝地（p.171–172） |
| 关系宫的喜忌与安稳 | 该宫位地支是喜是忌，是否被左右冲、刑、合 | 书证：戚继光妻宫巳火受左右双亥冲克（p.171）；康熙妻宫申金为用神而被巳合克（p.403） |
| 日主强弱与关系星的力量对比 | 身强比劫重则克财；身弱财多则不胜财 | 书证：p.408 身强比劫旺克制妻星；p.170–171 戚继光财旺身弱而「惧内」 |

关系星与关系宫按关系类型取用，见第 5 节。这一层项目里已经有现成引擎：`lib/baziStateAssessor.js` 的 `assessOriginalChartState` 就是按「十神 + 宫位」评估原局某一主题的稳定度，合盘可直接调用。

底色层不进「缘」的评分，它决定的是**上限与稳定度**：底色安稳的两个人，中等的互动也能长久；底色动荡的人，再好的合也容易被岁运冲开。

### 4.2 第 1 层 互济：气的补益与损耗

单盘的综合评价落在喜忌上：哪些五行是这个命局需要的，哪些是它的病（p.403）。互济层问的是：**对方这张盘，整体上是在给我送药，还是在加重我的病。** 这是合盘中理论基础最扎实的一层，也是民国以来批评俗传合婚、主张以两造喜用相互补救的思路所在（通行·待核：袁树珊《命理探原》论合婚）。

| 证据 | 判定 | 方向 | 依据 |
|---|---|---|---|
| 喜用互济 | B 盘中旺而有力的五行，是 A 的用神或喜神 → A 受益；是 A 的忌神 → A 受损 | 有向 | 推演（来自 p.388–403 的扶抑与喜忌） |
| 日主入用 | B 的日主五行正是 A 的用神或喜神。日主代表「这个人本身」，分量高于 B 盘里的其他字 | 有向 | 推演 |
| 调候互济 | A 的调候用神（如冬生喜丙、夏生喜癸）在 B 盘天干透出或居日柱；或两人生月寒暖燥湿相反而互补 | 有向 | 推演（来自第七章调候；p.389–390） |
| 病药 | A 命局最重的病（过旺的忌神），B 盘恰有制它或泄它的有力之神 → 得药；B 盘反而生扶它 → 增病 | 有向 | 推演（来自第七章「病药说」） |
| 伤用 | B 盘的旺神正克 A 的用神，且 A 的用神本就孤弱 | 有向 | 推演 |
| 通关 | A 盘两行交战，B 盘带来中间一行 | 有向 | 推演（来自第八章「源流和通关」） |

三条约束：

- **扶抑方向要用引擎的结论，不能按十神名目预设善恶。** 陆著强调十神的「善」与「凶」取决于它在具体命局里的作用（第六章「善神」与「凶神」一节）。对身强的人，对方的官杀是良药；对身弱的人，同样的官杀是压力。「七杀一律扣分、食神一律加分」是错的。
- **特殊格局要降低置信。** 从格、专旺格的喜忌与普通格相反（第八章）。引擎判为特殊格局、或强弱处于临界的命盘，互济层的结论标为低置信。
- **过犹不及。** 互济是补偏，不是越多越好。B 盘某行占比极高且正是 A 的用神，是「得济」；但若 A 的用神本已不缺，再加就是多余。实现时互济量应乘以 A 对该行的需求程度。

### 4.3 第 2 层 勾连：两盘干支的合冲刑害

这一层把两张盘的八个干、八个支两两相对，找出跨盘的作用关系。法则直接取自单盘的刑冲会合（第五章，表 5.8）。

**关系种类**

| 类别 | 关系 | 性质 |
|---|---|---|
| 天干 | 五合 | 牵系，有情 |
| 天干 | 相克（同性为七杀式的克，异性为正官式的克） | 制约 |
| 天干 | 相同（伏吟） | 同气，叠加 |
| 地支 | 六合、三合与半合、三会 | 牵系；其中「补局」值得单列：A 有申子、B 有辰，两盘合起来才成水局 |
| 地支 | 六冲 | 动荡、对立 |
| 地支 | 相刑、相害（穿） | 磨损、暗耗 |
| 地支 | 相同 | 同气；辰午酉亥相同时兼有自刑 |
| 整柱 | 天合地合（如甲子与己丑） | 牵系最强（通行·待核，俗称鸳鸯合） |
| 整柱 | 天克地冲（如甲子与庚午） | 张力最强。书证见于流年：康熙甲寅年与日柱戊申天克地冲而丧后（p.408） |

**位置权重。** 作用落在哪个柱位，意义不同（宫位含义取自 p.166 图 6.2，延伸到双盘为推演）：

| A 的柱位 | 含义 | 与 B 同柱位相作用时的解读 |
|---|---|---|
| 日干 | 自己 | 两个人本身的关系原型（见 4.4） |
| 日支 | 配偶宫，最贴身的位置 | 亲密关系中分量最重；朋友关系中表示私下相处的舒适度 |
| 月柱 | 父母兄弟宫，也是提纲、社会面 | 日常节奏、价值观、家庭与社交圈的相容 |
| 年柱 | 祖上、根基 | 家世背景、早年环境；俗法合婚主要看这一柱，本模型权重最低 |
| 时柱 | 子息、晚景、内心所求 | 长期目标、子女问题；时辰不详时整层缺失 |

日柱对日柱最重，日柱对月柱次之，年柱与时柱最轻。年命层面的生肖冲合降到民俗层（见 4.6），理由是陆著第四章所述命理学从古法「以年为主」转向今法「以日为主」的历史演变。

**从牵系到顺逆。** 按 P4，每一条跨盘关系先记为「牵系」或「张力」，再对受作用的一方判顺逆：

- 冲、克落在 A 的忌神上，是去病，对 A 有益；落在 A 的用神或用神之根上，是伤用，对 A 有损。
- 合住 A 的忌神是益；合绊 A 的用神是损，但牵系仍然成立。这正是「明知不合适却分不开」的命理结构。
- 两盘补成的三合三会局，看所成之局的五行对两人各自是喜是忌。同一个局，可能对一人是喜、对另一人是忌。
- 冲日支另有一层含义：不论喜忌，配偶宫被冲即是此宫不安（书证见于流年，p.171–172、p.408；延伸到对方盘为推演）。婚恋合盘中单独提示。

### 4.4 第 3 层 角色：十神与宫位的映射

**日干互见的六种原型。** A 的日干在 B 眼中是某个十神，B 的日干在 A 眼中也是某个十神，这两个十神必然成对出现，一共只有六种组合：

| A 看 B / B 看 A | 五行关系 | 关系原型 | 说明 |
|---|---|---|---|
| 比肩 / 比肩 | 同行同性 | 同道 | 同气相求，平等，也容易所求相同而相争 |
| 劫财 / 劫财 | 同行异性 | 竞合 | 相近而有别，亦友亦争 |
| 食神 / 偏印 | 相生同性 | 供养与受养 | 一方输出，一方吸收；生者泄气，受者得助 |
| 伤官 / 正印 | 相生异性 | 启发与庇护 | 同上而更有情；受生一方如得母护 |
| 偏财 / 七杀 | 相克同性 | 驾驭与受制 | 一方主导，一方承压；无情之克 |
| 正财 / 正官 | 相克异性 | 相合 | 即天干五合，阴阳相克而相合 |

最后一种正是陆著所说的「夫妻克合」：「男女因克相合，而阳性克合阴性，两者阴阳相克相合以成家室」（p.169）。日干正财对正官的十种组合，恰好就是五对天干五合，二者是同一件事。这是六亲网络里夫妻关系的原型，在合盘中应当是牵系最强的日干关系。（书证的延伸）

原型只描述**相处的形态**，顺逆仍由喜忌决定：对一个身弱喜印的人，「受养」是恩；对一个印重身强的人，同样的「受养」是溺。潘子端曾以荣格类型配八格来描写性格（p.368–371），陆著指其外向内向的二分有生搬硬套之处（p.372–373），所以这里的原型只用作相处形态的取象，不作性格类型学的断言。

**星宫互见。** 进一步看对方是否「落在」我命局中这类关系的星和宫上：

| 证据 | 判定 | 依据 |
|---|---|---|
| 星见 | B 的日主五行，是 A 的关系星五行（如 A 为男命以财为妻，B 日主正是 A 的财） | 推演（来自 p.166–169 六亲十神） |
| 星透 | B 的日干，正是 A 盘中透出的那颗关系星本字 | 通行·待核 |
| 宫合 | B 的日支或日干，与 A 的关系宫（婚恋为日支）成六合、三合，或 A 的日支藏干中有 B 的日干 | 通行·待核 |
| 宫冲 | B 的日支冲 A 的日支 | 推演，见 4.3 |
| 喜忌校正 | 上述「星」对 A 是喜是忌。星见而为喜，是良缘之象；星见而为忌，是「有缘而累」 | 书证的延伸（p.408 妻星为喜用故贤妻可期） |

**关于性别与取星。** 传统以「男看财、女看官」取配偶星，这取决于**本人**的性别，与对方性别无关，因此对同性伴侣同样可用。陆著也指出传统命理带有阳贵阴贱、官本位等时代印记（p.431–432），所以本模型的处理是：配偶星只作为「角色」层的一项证据，不单独决定结论；用户未提供性别或不愿按传统取星时，改用不分性别的日支宫位与日干原型，并注明。

### 4.5 第 4 层 同步：岁运的时间维度

原局的合冲是一辈子不变的，但关系有起落。这一层回答「什么时候」。

| 证据 | 判定 | 依据 |
|---|---|---|
| 大运同步 | 逐个时间段比较两人大运的喜忌走势：同升、同降、一升一降。长期一升一降的组合，容易出现境遇落差 | 推演（来自第五章大运流年） |
| 关系引动年 | 流年与某人的关系宫成合或冲，或其关系星透出。书中三例都是这样定应期的 | 书证：戚继光乙巳年用神出现而成婚（p.170）；苏轼甲午年午亥暗合妻宫而成婚，乙巳年巳亥冲妻宫而丧妻（p.171–172）；康熙甲寅年天克地冲日柱而丧后（p.408） |
| 共振窗口 | 同一年里，两人的关系宫或关系星**都**被引动。这样的年份关系容易有实质变化，方向（进或退）须结合当年对各自的喜忌 | 推演 |
| 岁运补局 | 两盘之间缺一字的合局，被流年补全；或原有的合被流年冲开 | 推演（来自 p.411–412 填实与冲破的分析） |
| 交运点 | 任一方换大运的前后一两年，个人状态变化大，关系随之需要重新磨合 | 推演 |

引动年只说「易有变化」，不说「必成」或「必散」。书中同样是冲妻宫，戚继光是夫人晚年离去（p.171），苏轼是丧妻（p.172），事象并不相同。

### 4.6 辅证层：神煞与民俗

陆著把神煞定位为综合评价之外「又一个视角」（p.403），合盘沿用这个定位。

| 项目 | 内容 | 待遇 |
|---|---|---|
| 贵人互见 | A 日干的天乙贵人，正是 B 的日支或年支 | 通行·待核；小权重辅证 |
| 桃花、红鸾天喜、孤辰寡宿 | 属于个人盘的神煞 | 归入底色层的辅证，不作跨盘判断 |
| 生肖六合三合、六冲相害 | 年支之间的关系 | 民俗；展示为文化常识，不计分 |
| 纳音相生相克 | 年命纳音 | 民俗；同上 |

不计分而保留展示的理由：用户普遍听说过「属相合不合」，完全不提会显得报告缺了一块；但它只用到八个字里的一个，信息量太低，不应影响结论。报告里可以明确说一句：属相是民间最流行的合婚法，本报告以日主与全局为主。

## 5. 关系类型：取用表与相处密度

不同的关系，看不同的星和宫，耦合的紧密程度也不同。

| 关系类型 | 关系星 | 关系宫 | 相处密度 | 侧重的层 |
|---|---|---|---|---|
| 婚恋 | 男财女官（按本人性别），兼看食伤（子女、情趣） | 日支为主，时柱为辅 | 高 | 五层全用；日柱权重最高；同步层最重要 |
| 朋友 | 比劫（同辈），兼看食伤（玩得来）、印（照应） | 月柱为主，日支为辅 | 低 | 角色、互济为主；勾连只看日月两柱；同步层从简 |
| 合伙与同事 | 财（利益）、官杀（规则与分工）、比劫（分利） | 月柱为主 | 中 | 互济、角色为主；重点看财与比劫的关系（合作生财还是相争夺财） |
| 亲子 | 父母看子女：男官杀、女食伤；子女看父母：印为母、偏财为父 | 上对下看时柱，下对上看月柱 | 高，但随年龄递减 | 互济为主；角色天然不对称，不套日干原型的「竞合」「驾驭」文案 |

十神与六亲的对应取自陆著 p.166–169；其中兄弟宫位置依徐大升的今法模型归在月柱（p.166）。朋友、合伙没有对应的传统六亲，取比劫与财官是按十神的社会功能（第六章「财官网络」）类推，属推演。

相处密度进入计算的方式：它是互济层与勾连层的总系数。同样的互济量，对同住的伴侣是日日浸润，对一年见几次的朋友则影响有限。

## 6. 综合评价：四问

单盘的综合评价是「取什么为用，何为喜忌，病在哪里，药在哪里」（p.403）。双盘的综合评价对应为四个问题。

| 四问 | 含义 | 主要来源 |
|---|---|---|
| **缘**：有没有牵系 | 两张盘之间有多少实质的勾连。牵系少的两个人，谈不上合与不合，只是各走各路 | 勾连层的合与补局；角色层的日干原型、星宫互见 |
| **和**：处得顺不顺 | 日常相处的摩擦程度 | 勾连层的冲、刑、害、克，尤其落在日柱和月柱上的 |
| **益**：谁滋养谁 | 分方向给出：A 从 B 处得到什么，B 从 A 处得到什么 | 互济层全部；勾连层的顺逆判定 |
| **久**：走不走得久 | 关系的稳定度与时间走势 | 底色层；同步层 |

四问不合成一个「吉凶」总分，因为它们彼此独立，组合起来才有意义：

| 缘 | 益 | 结构 | 说明 |
|---|---|---|---|
| 深 | 双向为正 | 相成 | 既分不开，又彼此成就 |
| 深 | 双向为负 | 纠缠 | 牵系很强却互相消耗，最需要提醒的一种 |
| 深 | 一正一负 | 偏济 | 一方得益一方付出，关系能否持久看付出一方的底色与意愿 |
| 浅 | 双向为正 | 淡益 | 君子之交，往来不多但有益 |
| 浅 | 双向为负或接近零 | 平行 | 没有多少作用，也谈不上伤害 |

「和」是这张表之上的修饰：同为「相成」，和则顺遂，不和则是「吵吵闹闹过一辈子」。「久」给出时间上的判断：底色安稳、大运同步的组合，上述结构可以长期维持；否则要看具体年份。

线上「朋友合盘」需要一个总分和称号来做分享，可以由四问加权得到（见工程文档）。但文案和判断应当以四问的组合为准，总分只是它的投影。

## 7. 跨体系侧验：紫微与西洋星盘

项目已有紫微排盘（iztro）和西洋星盘（astronomy-engine）两套引擎。合盘可以用它们做侧验，原则沿用 issue #23 与紫微设计文档的做法：**各体系独立得出结论，只比对方向，不把分数揉在一起。**

| 体系 | 可用的合盘方法 | 资料状态 |
|---|---|---|
| 紫微 | 各自夫妻宫（或交友、兄弟宫）的星曜与四化，作为底色层侧验；以对方生年干四化飞入我的盘，看落在哪些宫 | 飞入对方命盘的方法（俗称太岁入卦）在现有的《飞星紫微斗数》书摘里没有，属通行·待核，需要补充来源 |
| 西洋星盘 | 比较盘：两人日、月、金、火、上升之间的相位；对方行星落入我的宫位 | 相位与宫位计算引擎已有；合盘相位的解读口径需要另立 |

三套体系都要求准确的出生时间，紫微和上升星座尤其敏感。时辰不详时侧验层整体关闭。结论一致时提高置信，不一致时如实写「不同体系口径不一」，不强行调和。这一层排在分期的最后。

## 8. 局限与输出口径

陆著第十二章列出的四点局限，对合盘每一点都更严重，输出口径据此制定。

| 局限（陆著） | 对合盘的含义 | 输出口径 |
|---|---|---|
| 概率性描写，不是因果（p.424–425） | 两个人的相处，后天因素的比重比个人命运更大 | 全部结论用倾向性措辞；不出现「必」「注定」 |
| 「四同」八字命运不同（p.425–428） | 同样两组八字的两对人，结果可以完全不同 | 报告说明：这是两张盘的结构关系，不是对这两个人的判决 |
| 取象比类的主观性与模糊性（p.429–431） | 「相合」「相冲」到具体生活事象的映射并不唯一 | 每条结论附可核对的证据（哪两个字、什么关系），让用户自己对照 |
| 世俗价值观的印记（p.431–432） | 传统合婚带有男尊女卑、克夫克妻一类的价值判断 | 不使用克夫、克妻、旺夫、败家等标签；不按性别给出不对称的评价 |

另有三条来自产品责任的禁区：不对是否结婚、分手、离婚给出指令性建议；不预测对方的寿夭、重病、出轨；被合盘的另一方通常没有同意过被分析，报告不对其人品下断语。

## 10. 待核与开放问题

1. 传统合婚文献入库：《三命通会》论夫妻诸篇、《滴天髓》夫妻章、《命理探原》论合婚。核对后可把「星透」「宫合」「天合地合」「贵人互见」等通行说法升级或剔除。
2. 「对方如运」的力度系数没有文献依据，只能靠经验校准。建议用用户自己熟悉的若干对关系做人工评议。
3. 日干原型的文案如何避免性格类型学式的武断，需要在文案评审时把关。
4. 紫微飞入对方命盘的方法需要补充书证。
5. 晚子时沿用项目已定口径（23 点不换日柱）。合盘页面按时辰选择出生时间，子时的归属与个人档案是否完全一致，需要在实现时核对。
