## 1. 教材方法论锚点（NotebookLM 反查结论）

陆致极事业动态分析的主干是一条**三步链**，且吉凶判断**不走"五行喜忌"的捷径**。

### 1.1 三步推演链

| 步骤 | 看什么 | 对应本项目模块 |
|---|---|---|
| **第一步 原局结构判断**（定基调与天花板） | 锁定**事业星**（官杀＝权力职位、正偏印＝名誉/印把子）与**事业宫**（月柱）；评估日主强弱、调候需求、主导格局，找出事业潜质与原局之"病"（官杀混杂、身弱杀重等） | `natal_context` → 事业 `DomainBaseline` |
| **第二步 大运建场**（定十年环境与焦点） | ①**运限并轨**：把大运与当前年龄的四柱运限对位（30 岁看月柱、40 岁看日柱）；②**应局/引动**：扫描大运干支是否在原局重现（应局），或是否为原局事业星的"原身与禄"（引动）——如原局有丁火正印，大运走到巳（丁之禄），即名誉权柄在此十年被激发 | `dynamic_state.dayun_state` ＋ `dynamic_relations`（scope=dayun_to_natal） |
| **第三步 流年触发**（定具体应期与吉凶） | 流年**先与大运、再与原局**发生关系；重点找"冲/合/刑"是否打破静止或解除羁绊；最后做**吉凶否决检查**（见 1.2） | `dynamic_state.year_state` ＋ `possible_events` |

> 引文：「不能简单地谈论运岁的五行所喜所忌，而必须回到原局结构去」「流年首先跟大运发生关系，然后再跟八字原局发生关系」——动态分析教程。

### 1.2 吉凶方向判断规则（关键，对应审计 R7 指标解耦）

事业断吉凶**不能只看引动十神是喜是忌**，按优先级：

1. **干支扭曲否决（最高优先级）**：大运/流年若与**月柱（事业宫）或日柱**构成"一级干支扭曲"（天克地冲），属原局结构坍塌——**无论引动喜忌，通常断凶**（罢官、降职、官非、破败）。
2. **状态突变的物理性质**：冲合若是"解除羁绊 / 合入事业宫 / 能量流通顺畅"→**吉**（升职掌权）；若是"破局"（合化改变核心官星性质、冲毁印星唯一根基）→**凶**。
3. **喜忌只是底色，不是判据**：即使引动的是五行喜用，若与原局强烈交叉对抗，仍可为凶。

⇒ 工程含义：`auspice_direction` 必须**先过干支扭曲否决，再看冲合性质**，最后才参考喜忌作为权重微调。这正是 R7 要求的"激活 ≠ 吉凶"。

### 1.3 运限（G1）在事业里的特殊意义

- 年柱 1–16、月柱 17–32、日柱 33–48、时柱 49–64；大运按时序"走进原局"，吉凶力量重点投射到对应运限柱。
- **月柱双重身份**：既是事业宫，又对应 17–32 岁——青年立业窗口。青年大运切入月柱时，引动的星宫状态**直接决定事业起点的社会层级**。
- **冲提运伏笔**：约第六步大运（50–60 岁）干支必与月柱天克地冲（冲提运），摧毁青年期建立的社会门户 → 解释退休/退居二线/事业滑坡。事业线必须能标出这个结构性凶段。

## 2. 可复用的教材命例（作为 golden flow 模板）

教材给了两个**结构干净、机制典型**的事业命例，直接作为本线的流程模板与回归测试。

### 案例 A：意外升职（当选全美学会主席）

- 四柱：**壬寅 / 辛亥 / 戊辰 / 癸丑**（1962-11，戊土日主，生亥月）
- 第一步 原局：戊土生初冬亥月，水旺寒重，**急需火调候**；财（水）旺需印（火）生身任财。事业潜质押在「印」上。
- 第二步 大运（55 岁 **丁巳**运）：
  - **运限**：55 岁 → 时柱段，晚景收成。
  - **引动**：地支【巳】＝戊土之**禄**（自身落脚点）；其上透天干【丁】＝**正印**（名位/权力/社会背书）。⇒「自身（巳禄）承载了名誉地位（丁印）」，事业进入巅峰场域。
  - **调候**：丁巳南方火，正补原局最急的暖局用神——**调候 × 事业星同一个字（丁火）双重命中**。
- 第三步 流年（2017 **丁酉**）：流年天干再现【丁】＝**应局（应拨）**，直接激活大运头上的丁火正印。⇒ 正印被彻底引动，名誉降临到代表自身的禄上 → 未主动谋求而获最高荣誉职位。

### 案例 B：升任副市长

- 四柱：**甲午 / 癸酉 / 戊寅 / 丁巳**（戊土日主，甲木＝七杀＝官位）
- 原局：伤官生财、财生七杀（甲），官位之象已成。
- 大运（43 岁 **戊寅**）：戊＝比肩（**日主自己到位**）；【寅】＝原局【甲木七杀】之**禄** ⇒「大运引动原局七杀」＝命主自坐官位；且寅午合化印局制杀 → 权力稳固，升任副市长。

### 2.1 抽象出的事业 golden flow（引擎须能复现）

```text
1. 原局：定事业星(官杀/印) + 事业宫(月柱) + 调候需求 + 格局
2. 大运：
   a. 运限对位（年龄→柱）
   b. 应局：大运干支是否在原局重现？
   c. 引动：大运干/支是否＝原局事业星的 原身/禄？（跨干支 G3）
   d. 调候：大运是否补原局急需之气？（若补的字＝事业星，双重命中，强信号）
2'. 大运建场结论 = 事业星是否在这十年被"激发/承载"
3. 流年：
   a. 流年干支是否＝大运/原局事业星的 应局/引动？（激活）
   b. 冲合性质 + 干支扭曲否决 → 方向(吉/凶)
   c. 产出事件：激活强 + 方向吉 → 升职/掌权；方向凶 → 官非/降职/破败
```

两案例共同点：**引动事业星的不是"刑冲合害"，而是"禄/原身"的隔空互通 + 应局重现**——正是当前系统缺失的 G2/G3。这条线必须把 G2/G3 补上才能复现教材结论。

## 5. 模块二：事业状态分（`domain_impacts.career` + `metrics`）

### 5.1 先天承载 `base_capacity`（静态，原局一次）

事业 baseline 由原局**事业星 + 事业宫 + 格局**决定，复用 `baziStateAssessor` 对 `career_business` TargetSpec 的评估：

| 成分 | 看什么 | 现有来源 |
|---|---|---|
| 事业星强度 | 官杀/印/食伤 是否透干、通根、十二运旺衰 | `baziStateAssessor` 星状态 |
| 事业宫稳定 | 月柱是否被原局刑冲、盖头截脚 | `baziStateAssessor` 宫状态 |
| 格局完整度 | 正官格/七杀格/食伤格 成败、用相神 | `baziCore` `pattern_analysis` |
| 任职能力 | 身强弱 vs 官杀轻重（身弱杀重＝承载不足） | `BaziRuleEngine.calculateStrength` |

`base_capacity = 加权(事业星, 事业宫, 格局, 任职能力)`，0–100，**只算一次**。

### 5.2 当年状态分 `current_state_score`（动态，扰动式 G4 / 遵守 R1）

> **R1 红线：不是把大运流年当新柱重排盘。** 在 `base_capacity` 上叠加有限扰动量。

按 PRD §20 的 components，事业线落地为：

| component | 事业含义 | 增量来源 |
|---|---|---|
| `star_state` | 事业星这十年/这一年被激发还是被克合 | 大运/流年 应局·引动·冲合事业星 |
| `palace_state` | 月柱(事业宫)是否被引动/被冲 | scanner: 岁运 vs 月柱 |
| `pattern_integrity` | 格局是否被岁运成全或破坏 | G4 扰动：合化是否改官星性质 |
| `climate_fit` | 调候是否被补足（案例 A 关键） | `calculateTiaohouRatio` 岁运乘数 |
| `circulation` | 财生官/官印相生 通路是否接通 | 通关规则 + 岁运 |
| `global_fit` | 引动十神是否原局喜用 | 喜忌分层（**仅作底色权重**） |
| `trigger_direction` | 当年方向（吉/凶），见 §7 | 干支扭曲否决 + 冲合性质 |

```text
current_state_score(career, t)
  = clamp( base_capacity
           + Σ component_delta(t)     // 扰动，带阻尼/限幅
         )
```

**关键约束（来自 R1/R2/R7）**：
- 单个流年比劫/印星**不重算日主强弱档位**，只调 `star_state`/`climate_fit` 的增量；
- 合化对 `pattern_integrity` 的影响**限幅**，存疑化局不得直接翻成"破格"；
- `current_state_score`（结构顺遂）与 `activation`（激活强度）、`trigger_direction`（方向）**三者独立输出**，不可互相换算。

### 5.3 三类独立指标（PRD §20.1，事业线取值）

| 指标 | 事业含义 |
|---|---|
| `state_score` | 当年事业结构适配度（高＝条件有利，≠一定升职） |
| `activation` | 事业星/宫被岁运触发的强度（高＝这年事业易有事，≠好坏） |
| `volatility` | 相对相邻年/原局的变化幅度（高＝事业大起大落概率） |
| `confidence` | 证据一致度（应局+引动+运限同时命中则上调） |

## 6. 模块三：动态关系 `dynamic_relations`（事业相关机制）

事业线需要的 `mechanism`，按是否已实现分三类：

| 机制 | 事业意义 | 现状 |
|---|---|---|
| 冲动 / 合动 / 合化 / 三合 / 六害 | 事业宫被动/格局变性 | ✅ `baziRelationScanner` 已有 |
| 整柱伏吟 / 反吟 | 事业反复/坍塌 | ✅ `baziDynamicAssessor` 已有 |
| **应局_同干 / 应局_同支** | 岁运重现原局事业星之字＝激活（案例 A 丁酉的丁） | ⚠️ **新增 G2**（现仅整柱伏吟） |
| **原身引动 / 禄引动** | 岁运干↔原局支、支↔原局干 跨层激发事业星（案例 A 巳禄引丁印；案例 B 寅禄引甲杀） | ❌ **新增 G3** |
| 透干引动 | 大运/流年透出事业星 | ✅ 部分已有 |
| **一级干支扭曲** | 天克地冲事业宫/日柱＝凶否决 | ⚠️ 需作为独立 `direction` 否决项显式输出 |

每条关系按 PRD §18 `DynamicRelation` 输出，事业线必须填：
- `affected_domains` 含 `career`；
- `activation_strength`（强度）与 `direction`（吉/凶/混合）**分离**；
- `target_change`（事业星/宫 before→after）；
- `evidence_text`（如"大运巳为日主戊之禄，引动其上丁火正印"）。

### 6.1 G2/G3 的事业判定算法（新增）

```text
事业星集合 S = {官,杀,正印,偏印}（用 baziTargetElement career_business 的 primary_shishen）
对每个 s∈S 在原局的落点(干/支/藏干)：
  应局：岁运干支 == s 所在的干 或 支            → 应局_同干/同支
  禄引动：岁运支 == (s所在天干)的禄              → 禄引动
  原身引动：岁运干 == (s所在地支主气)的透出      → 原身引动
命中即产出一条 relation，scope 标 dayun_to_natal / liunian_to_natal
```

> 禄表、原身（地支藏干↔天干）映射是纯查表，工作量小；这是复现教材结论的最小必要新增。

## 7. 模块四：可能事件 `possible_events`（事业 + 吉凶否决）

按 PRD §21，事业事件生成顺序：

```text
1. 有领域落点（career 被有效引动）才生成 → 否则不输出（不凑数）
2. 方向判定（§1.2 优先级）：
   a. 干支扭曲否决：岁运 ⟂ 月柱/日柱 一级扭曲？ → 强制 risk
   b. 否则看冲合性质：解绊/合入事业宫/通路顺 → opportunity；破局 → risk
   c. 喜忌仅微调置信，不翻转方向
3. likelihood_level：
   high  = 应局/引动有效 + 运限命中 + 方向明确
   medium= 仅大运建场未到流年触发（标"趋势/背景"）
   low   = 仅流年触发但大运不承载
4. event_type 映射（事业）：
   opportunity → 升职/掌权/平台跃迁/获权责
   risk        → 官非/降职/革职/事业破败/被动变动
   mixed       → 事业变动方向未定（如跳槽/转型）
5. state_transition：升职=entry/change；冲提运退居=exit；维持高位=persistence
6. 每条带 supporting_relation_ids + blocking_relation_ids + disclaimer
```

事业事件模板（接 `baziTargetElement` 已有 `key_questions`，复用其语义）：

| 方向 | event_type 候选 | 触发结构 |
|---|---|---|
| opportunity | 升职掌权 | 官杀/印 被应局或禄引动 + 无扭曲 |
| opportunity | 平台跃迁/创业得位 | 食伤生财、财生官通路被接通 |
| risk | 官非/革职/降职 | 岁运 ⟂ 月柱/日柱 一级扭曲；伤官见官 |
| risk | 事业破败/根拔 | 印星唯一根被冲合、格局破 |
| mixed | 跳槽/转型/被动调动 | 事业宫被冲动但未扭曲 |

| 能力 | 复用现有 | 新建/补齐 |

| 事业星/宫映射 | ✅ `baziTargetElement` `career_business` + `career_direction` | — |

| 原身/禄引动 | ❌ | **G3**：禄表 + 原身映射 跨层扫描 |
| 运限并轨 | ❌ | **G1**：年龄→柱 纯函数 + 冲提运检测 |

## 9. 验收：用教材命例做 golden test

下表是从教材反查出的 **9 个四柱齐全的事业命例**（NotebookLM「八字/奇门古籍」笔记本），覆盖吉/凶/混合与多种引动机制，作为事业线回归测试集。其中 A、B 在 §9.1/§9.2 给出详细推演断言，其余按机制归类。

> 注：① 戚继光在原典中仅给出部分干支，未入选（不编造缺字段）。② 这些是 OCR 教材命例，**硬编码进测试前需逐个核对四柱排盘**（审计 §9 的 OCR 噪声警告）。③ G/H/I 偏静态结构，主要验 `base_capacity` 与方向；A–F 含明确大运/流年，验动态应期。

## 10. 落地顺序（事业线内部分期）

1. **G1 运限纯函数** + `temporal_context.yunxian`（含冲提运）——零风险，先做。
2. **G2/G3 应局·禄·原身 扫描**——复现教材结论的最小必要；先只跑事业星集合 S。
3. **事业 baseline + 状态分扰动（G4 事业切片）**——遵守 R1 扰动式，限幅。
4. **吉凶否决 + 事件生成**——接 §7。
5. **9 个 golden case 回归**（§9，含 D/E/I 凶向校验）——通过即 MVP 事业线达成。

完成后再横向复制到 学业/婚姻/财富（它们的 TargetSpec 已在 `baziTargetElement` 就绪），即 PRD §28 R5 的 P1 阶段。

## 11. 基于 9 个 golden case 的遗漏要素审计

用 9 例反向检查 §1–§8，发现框架存在一个**系统性偏向**：现有设计以"事业星 → 事业宫 → 被引动"为主轴（继承自 `baziStateAssessor` 的 target-element 路径）。但在这 9 例里，**C / E / F / I 四例的吉凶主要由"全局格局 / 势"决定，并没有明显的事业星被直接引动**。若事件触发器只问"事业星被引动了吗"，会整片漏判。以下为补充要素。

### 11.1 最关键的一条：双路径触发（E1）

> 教材反复强调"必须回到原局结构去"。事业吉凶有**两条并行路径**，任一条都能触发事件，且**全局路径常压过星宫路径**：
>
> - **路径甲（星宫引动）**：官杀/印/食伤 被 应局/禄/原身/冲合 引动 —— 已在 §6 覆盖。
> - **路径乙（全局格局/势突变）**：岁运改变了原局的旺衰格局、用神方向或主导势 —— **当前缺失**。

⇒ 工程动作：§7 的事件生成条件 `1. 有领域落点（career 被有效引动）` 必须扩成 **`career 被引动 OR 全局格局/势发生突变`**；`dynamic_state`（G4 事业六维扰动）的输出要能驱动事件，而不仅作为分数。

### 11.2 遗漏要素清单

| 编号 | 遗漏要素 | 案例证据 | 当前状态 | 接入位置 |
|---|---|---|---|---|
| **E1** | 全局格局/势路径与星宫引动**并行触发** | C 去寡 / E 逆势 / F 转换 / I 旺神发作 | 缺：事件只从"事业星被引动"起 | §7 触发条件 + `dynamic_state` 驱动事件 |
| **E2** | 事业星的**制化配置**决定引动是吉是凶 | B 七杀得印化=权 / E 伤官无制=犯上 / F 食神制杀 | 缺：事业星被扁平列举 | baseline 新增"事业星配置状态"；§1.2 方向判据前置 |
| **E3** | **羊刃**结构两面性（驾杀=贵 / 逢生发作=祸） | I 丙午羊刃，木运生火助刃→破败 | 缺 | baseline 结构识别 + 凶向规则 |

### 11.3 明确划为 MVP 非目标（标注而非遗漏）

- **流月级应期**：D 案精确到"乙未年己丑月"。MVP 为**年级**，流月留待后续；但年级判定要能命中 D 的 2015。
- **取象 / 物象**：G 案"戊土＝平台/讲台"属象法联想，难系统化，列为后期；MVP 用 `career_direction` 的格局→行业映射兜底即可。

### 11.4 对落地顺序的影响

E2（制化配置）与 E1（双路径）应**并入 §10 第 3–4 步**，否则 B（七杀）、E（伤官）、F（格局转换）、I（羊刃）四例跑不出正确方向——它们恰好占凶向/复杂案例的大半。E3/E6/E8 可作为 baseline 识别的增量，E5/E7/E9 优先级稍低，可在事业线跑通后补。

> 一句话结论：框架的"星宫引动"主轴对 A/B/D 够用，但要覆盖 C/E/F/I，必须补上**"全局格局/势"这条并行路径**和**"事业星制化配置"这层前置判据**——这也再次印证审计 G4（全局重算）不是可选项。
