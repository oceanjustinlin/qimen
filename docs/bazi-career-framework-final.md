# 事业线最终分析框架（gold-case 收敛版）

> 日期：2026-06-20  
> 地位：**本文为事业线 MVP 的确定性规格**，取代前期探索稿中未被命例支持的部分。每条规则都用 [19 个原文核实命例](../fixtures/career-golden-cases/career-golden-cases.json) 标注证据（见 [golden-cases 文档](bazi-career-golden-cases.md)、[分析框架探索稿](bazi-career-mvp-framework.md)）。  
> 收敛原则：**只保留 19 例能证明的规则**；命例无法支持的设想一律移到 §8「明确不做」，不进引擎。

## 0. 一句话收敛

> 事业吉凶 = 在「原局画像」之上，对岁运跑**一个带严格优先级的方向决策过程**；分数是方向的派生量，激活强度独立于方向。

19 例全部收敛到 §3 的同一套规则（§7 真值表逐例验证）。

## 1. 原局画像（静态，算一次）

引擎从原局只需抽出 5 样东西，全部是后续决策的输入：

| 画像项 | 内容 | 命例依据 |
|---|---|---|
| **格局类型** | `普通格` 或 `特殊格`（从/专旺/润下/化气/阳刃） | 特殊格方向反向，决定走 R2 还是 R3：Q润下、I阳刃、R…(普通) |
| **事业星配置** | 官杀/伤官/羊刃/印 各自**有制 / 无制 / 被合化**的状态 | J有制↔K无制；U杀印；Z1-3制杀 |
| **用神 + 命门字** | 用神、相神(枢纽)，以及"怕冲/怕合之字" | T(午火印=命门)、V(印局)、Y(丙火枢纽) |
| **势** | 主导五行/旺神方向，及原局之"病" | C(火土旺·病在孤癸)、E(木火势) |
| **base_capacity** | 事业先天承载（官杀印格局完整度+任职能力） | R(金木间隔成器)、H… |

> 复用现有：`baziStateAssessor`(星宫)、`baziCore`(格局)、`BaziRuleEngine`(强弱)、`baziImageAssessor`(特殊格)。新增只是把「事业星配置」「命门字」结构化输出。

## 2. 引动层（岁运如何"碰到"事业星）— G2/G3/G7

判断岁运是否引动事业星，只有 4 种通道（按命例收敛，不多不少）：

| 通道 | 定义 | 命例 | 现状 |
|---|---|---|---|
| **透干** | 岁运天干 = 事业星 | A(丁=印)、F(丁=食) | ✅ 已有 |
| **应局** | 岁运干支 = 原局事业星之字（重现激活） | A(丁酉之丁应大运丁印) | ❌ 新增 G2 |
| **禄引动** | 岁运支 = 原局事业星天干之禄 | A(巳=戊禄)、B(寅=甲杀禄) | ❌ 新增 G3 |
| **原身引动** | 岁运干 = 原局事业星地支主气之透出 | （A/B 同源机制） | ❌ 新增 G3 |

> **不补 G2/G3，A 和 B 这两个最典型的升迁案根本判不出来**——这是引动层必做的最小集。

## 3. 方向决策过程（核心·确定性·带优先级）

`DIRECTION(原局画像, 岁运) → {吉 | 凶 | 中性}`，**严格按序短路**：

```
R1  结构坍塌否决（强制凶）
    连环刑冲(≥3 支接连)
    或 冲拔日主【唯一/关键】禄根（多根则不算）
    或 破局（旺神被冲、枢纽断流通）
    → 凶                                  〔D(八连支), E(双冲拔根), Y(壬申申冲寅根+枭夺食)〕
    ⚠️ 修正(实现核验)：天克地冲【提纲】本身【不是】自动凶——A(丁巳反吟辛亥)、
       J(丙戌反吟庚辰) 均反吟提纲却为吉（反吟带来日主禄/食神用神时反吉）。
       "冲提运"仅为转折信号，吉凶由所引动成分定。拔禄根须判"唯一性"：
       C(己土午禄但有丑巳多根)走水运反吉，单冲一禄根≠坍塌。
       ⇒ 工程上 R1 触发条件交由原局判断(连环/唯一根/破局)，不可单凭一个岁运干支自动断。

R1' 用神/枢纽被破否决（强制凶）
    岁运 冲破/合掉 原局用神、相神(枢纽)、或印局核心
    → 凶                                  〔T(子冲午印), V(卯酉破印局)〕

R2  特殊格局·顺逆（仅 pattern_type==特殊格）
    顺其旺神/化神      → 吉
    逆其旺神(冲/克/引忌) → 凶              〔Q(丙辰群劫·凶), I(卯·阳刃逢生·凶)〕

R3  普通格局·事业星制化（引动事业星时）
    得制化配合(七杀有印/食/刃；伤官有印/财；身杀两停) → 吉   〔A,B,J,U,F,Z1,Z2,Z3〕
    无制 / 见官 / 攻身                                     → 凶   〔K〕

R3b 去病 / 顺逆（未直接引动事业星时）
    去原局之病 / 顺原局之势 → 吉           〔C(去其寡), F(转格)〕
    助病 / 逆原局之势       → 凶           〔E(金水逆木火)〕

R4  喜忌兜底（以上不决时）
    引动喜用→偏吉 / 引动忌→偏凶；只调置信，绝不翻 R1/R1'
```

**三条铁律（收敛自命例，不可违反）：**

1. **R1/R1' 压一切**——即使引动的是喜用、即使是事业星，结构坍塌/用神被破仍判凶。〔T：子运是水(喜)但冲用神午火印→凶（R1' 压 R4）；D：连环刑冲→凶（R1 压一切）〕（注：K 庚辰为"引动七杀但无制"，走 R3 判凶）
2. **事业星不是中性的**——官杀/伤官/羊刃的吉凶取决于"配置(制化)"，不能当一颗好星直接加分。〔J↔K 同为七杀，有制吉/无制凶〕
3. **特殊格方向反向**——从/专旺/润下/阳刃命，顺势为吉、扶抑冲旺为凶，与普通格相反。〔Q/I〕

## 4. 三步推演（决策过程的时间装配）

```
第一步 原局 → §1 画像（事业星配置 / 用神命门 / 格局类型 / 势 / base_capacity）
第二步 大运 → ① 运限对位(G1)；② 引动扫描(§2)；③ 建场：跑 §3 得"十年方向倾向"
第三步 流年 → ① 应期：再跑 §2 引动 + 冲合；② 跑 §3 得"当年方向"；R1/R1' 否决在此终判
```

- **大运建场 ≠ 流年触发**：F/Y 是大运转格/建场，A/B/D 是流年点睛。引擎须分两层算（先 `dayun_state` 再 `year_state`）。
- **转折案**（SS/T/Y/Q）证明：同一原局，方向随运而变——所以方向必须**逐运逐年重算**，不能锁死。

## 5. 分数与指标（收敛：方向为主，分数为辅）

命例只硬性证明了**方向**，没有给绝对分。故收敛为：

| 输出 | 定义 | 来源 |
|---|---|---|
| `direction` | §3 决策过程结果（吉/凶/中性） | **一等公民**，命例直接验 |
| `activated_mechanism` | 命中的引动通道 + 触发规则(R1..R4) | §2 + §3 |
| `state_score` | `base_capacity` 经"方向×激活幅度"带阻尼调整（R1 扰动式，**不重排盘**） | 派生量 |
| `activation` | 引动强度（与方向**完全独立**） | §2 |
| `volatility` | 相邻年方向/分数变化幅度 | 派生 |
| `confidence` | 证据一致度：星宫+引动+运限同时命中则升档 | 派生 |

> 红线（R1/R2 评审）：`state_score` 是在 `base_capacity` 上叠**有限增量**，不是把大运流年当新柱重跑 `calculateStrength`；合化对格局的影响要限幅。

## 9. 收敛结论

事业线最终框架坍缩成**三件确定的东西**：

1. **原局画像 5 项** → 喂给决策；
2. **引动 4 通道**（透干/应局/禄/原身，必补 G2/G3）→ 决定岁运是否碰到事业星；
3. **方向决策过程 R1→R4**（结构坍塌/用神被破否决 > 特殊格顺逆 > 事业星制化 > 去病顺逆 > 喜忌兜底）→ 19 例 0 反例。

> 一句话：**先看会不会塌(R1/R1')，再看是不是特殊格(R2)，否则看事业星有没有制(R3)、顺不顺势(R3b)，喜忌只兜底。** 分数与激活是这条主线的派生量，三指标始终分离。
