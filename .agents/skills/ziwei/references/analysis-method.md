# 紫微读盘方法

本文件是解读层的方法说明。所有盘面事实取自 `ziwei_skill_cli.cjs` 的输出；这里只规定**怎么读、按什么次序读、怎么措辞**。
标注"《飞星》pN"的条目来自《飞星紫微斗数》（中州古籍版），N 为书上印刷页码（PDF 页码 = N + 6）。
卷六 p249–270 已逐页校订登记在 `knowledge/ziwei/sources/feixing-ziwei/excerpts.jsonl`（ID 形如 `source.feixing-ziwei.p254.gui-ju-b`），可以作为方法依据引用页码；但这些条目尚未变成已审核命题，用在具体命盘上仍属 **C 级**：可以用来组织观察，不能当作确定结论。

## 一、读盘次序

古籍的总纲（《飞星》p251–252"看命总论""看命或法"）与现代资料（《命理天机》p416）一致：

1. **先定身命**：命宫、身宫所在，坐什么星，有没有主星。"欲安身命先辨时辰，时真则无不应"（p222）——时辰存疑时先处理时辰问题。
2. **看命宫根基**：命宫主星亮度、是否空宫、三方四正是否有吉星或煞星会照。
3. **再看主题宫**：事业看官禄，财运看财帛，感情看夫妻，整体看命宫；每个主题宫都按"本宫 → 三方四正 → 夹宫 → 四化"读。
4. **四化落点**：生年四化各落何宫，化忌所在与所冲。
5. **最后看运限**：大限定十年基调，流年定一年起伏。"大限既衰，小限何补；大限未倒，小限无妨"（p251）——**大限权重高于流年**，流年不能推翻大限基调。

## 二、宫位关系：正、合、拱、夹

《飞星》p250（已登记摘录 `source.feixing-ziwei.p250.relations`）：

| 术语 | 含义 | 证据包字段 |
| --- | --- | --- |
| 正 | 对宫 | `relation_set.opposite` |
| 合 | 三合 | `relation_set.trine` |
| 拱 | 四正（本宫 + 对宫 + 三合） | `relation_set` 全部 |
| 夹 | 前后邻宫 | `relation_set.adjacent`、`jia_palace` |

修正规则（同页）：夹宫虽凶，本宫有吉星正坐仍可论吉；夹星虽善，本宫有煞星也要论凶。**本宫优先于夹宫。**

读法：

- 本宫星曜决定"这件事是什么样子"，对宫决定"外部环境与对立面"，三合宫决定"支撑来源"。
- `sanfang_aggregate` 已经把三方四正里的吉星、煞星、禄存、天马、四化分好组（C 级口径），用它组织"支撑 vs 压力"两栏。
- 空宫（`palace_star_system.empty=true`）：按传统借对宫主星来看（`empty_palace_borrow`），要说明"本宫无主星，借对宫某某星参看，力量较弱"。古籍对空宫命宫的评价偏负面（p272"命无正曜"），只转译为"自我定位较依赖环境、可塑性高"一类倾向，不说"过房""飘流"。

## 三、星曜：亮度与组合

- **亮度以引擎为准**：`brightness` 取值 庙 > 旺 > 得 > 利 > 平 > 不 > 陷（`brightness_state.rank` 越大越亮）。书中的庙旺表与引擎可能不完全一致，不得据书改写。
- **同一颗星，亮度不同含义不同**：古籍几乎每条断语都分"庙旺"与"陷地"两种情况（如《飞星》p237–248"论身命十二宫吉凶星便览"）。亮度高时讲星的正面特质，亮度低时讲同一特质的消耗面或需要条件配合，而不是换成另一种性格。
- **组合优先于单星**：双主星同宫按组合读（紫府、紫杀、武贪、机梁、同阴、巨日、廉贞系等），再看辅星。
- **五行入宫**（p249–250"十二宫诸星生克制化论"）：星曜五行与宫位五行的生克会增减星力。属于 C 级，只在亮度信息之外作补充，不与引擎亮度冲突。
- **吉煞相杂**："诸星吉逢凶也吉，诸星凶逢吉也凶"（p151、p230）——任何判断都要同时看吉星和煞星，不能只取一面。

## 四、四化

- **生年四化**（`chart.natal_mutagens`）是 B 级事实：化禄 = 资源与机会的流入点；化权 = 主导、掌控与压力并存之处；化科 = 名声、条理与贵人；化忌 = 执着、阻滞、需要额外投入的地方。
- **化忌必须讲**：化忌所在宫与其对宫（所冲之宫）是整盘最需要提醒的地方，按"需要投入更多、容易反复"来讲，不讲成灾祸。
- **宫位影响四化效力**：《飞星》p249"十二宫禄权科忌庙照论"按地支列出禄权科忌的得地与否（已登记为方法性摘录 `source.feixing-ziwei.p249.mutagen-context`）。只用于说明"四化不能脱离落宫统一论吉凶"，不逐宫引用其吉凶结论。
- **禄逢冲破**："禄逢冲破，吉也成凶"（p228、p151）——化禄或禄存被化忌、煞星冲照时，资源面打折。
- **宫干飞化**（`flying_mutagen`）属四化飞星辅助视角，C 级：可以说"从飞星角度看，官禄宫干使某星化忌飞入某宫"，但与三合判断冲突时并列说明，不覆盖。

## 五、运限

- **大限**：`chart.periods[].decadal.life_palace_maps_to` 是这十年的"命宫"落点。读法：这十年的重心转到本命哪一宫的事务上，再看大限四化落入本命哪宫。
- **流年**：`chart.periods[].yearly` 同理，看流年命宫与流年四化。
- **主题宫在运限中的宫职**：从 `role_to_natal` 反查，例如问事业时看"大限官禄 / 流年官禄落本命哪宫"，以及本命官禄宫在运限中变成什么宫职。
- **作用点只认登记过的关系**（与仓库 Pipeline 一致）：
  - 同宫重叠：运限命宫或运限主题宫与本命主题宫重叠；
  - 对宫、三合、邻宫：运限四化或运限命宫进入本命主题宫的三方四正；
  - 运限四化落点：`period_mutagen`；
  - 多层叠化：`mutagen_stack`（C 级），如本命化忌的星在流年又化忌（忌叠忌）或转化禄。
- **变化只用五种措辞**：增强 / 削弱 / 转向 / 冲突 / 无明显变化。没有作用点时就说"该年对此主题的触动不明显"，不硬找。
- **流年神煞**（p263–264 太岁、博士十二神等）：引擎只给本命层的 `suiqian12`、`boshi12`。流年层神煞不在证据包内时不得自行推算引用。
- 古籍中"限至必死""黄泉""十无一生"等限运断语（p141、p252–253）一律不用。

## 六、格局速查（C 级）

格局只有在**全部成立条件都能在 `chart` 中逐条核对**时才能提，且必须说明"按古籍某某格的说法"。只符合一部分时，不得称为该格，可以说"有某某格的部分条件"。

运限与命局的搭配见 p256"定杂局"（`source.feixing-ziwei.p256.za-ju`）：枯木逢春（命衰限好）、吉凶相半（命有正星而限衰）、水上架屋（年运起伏不定）等，可作为"静态底色 × 动态变化"的古籍旁证。

古籍还有"十二宫诸星得地合格决""失陷破格决"（p259–262）"定富贵贫贱十等论"（p258–259）"十四等决"（p256–258）。这些条目把星曜位置直接对应到"公卿""富翁""盗贼""娼"等身份，**不得引用**，只能从中提炼"某组合在某宫亮度好、力量足"这一层。

## 七、断语转译

古籍原文多为确定性、身份化、性别化断语。报告中一律按下表转译（与 `knowledge/ziwei/policies/safety.yaml` 一致）：

| 古籍说法 | 转译方向 |
| --- | --- |
| 必主富贵 / 位至三公 / 金榜题名 | 该方面结构有力，条件具备时发展空间较大 |
| 贫贱 / 下格 / 不聚财 | 该方面需要更多经营，积累方式偏慢或偏辛苦 |
| 夭 / 寿促 / 限至必死 / 黄泉 | 不转述；如需提醒，只说"注意作息与体检" |
| 刑伤 / 疾 / 残 | 只说"这一宫位提示需要留意身体或安全"，建议现实专业意见 |
| 克妻 / 克夫 / 刑克六亲 / 重婚 | 关系中容易出现摩擦或距离，需要沟通与边界 |
| 淫 / 桃花犯主 / 风流 / 娼 | 情感表达丰富、社交吸引力强，需要关系边界意识（不区分性别） |
| 盗贼 / 奸诈 / 屠人 / 刑名 | 不转述 |
| 僧道 / 孤 / 过房 / 离祖 | 独立性强，与原生家庭的距离感，适合需要专注或独处的领域 |
| 女命宜 / 不宜某星 | 不区分性别，按同一套标准解读 |
| 官非 / 口舌 | 沟通与合规上需要多一分谨慎 |

## 八、每个结论的自检

写下一句判断前确认：

1. 它对应证据包里哪个字段？（找不到就删，或标为传统看法）
2. 它是 A、B、C 哪一级？措辞是否匹配级别？
3. 是否同时给了支撑面和压力面？
4. 是否落到具体宫位星曜，换一张命盘还成立吗？（还成立就是空话，删）
5. 是否触犯第七节的转译规则？
